# DartBasics
Look man,
I didn't sit down yesterday to write a definitive, enterprise-grade masterclass on Dart. I was sitting thinking to do something (most likely productive)
and God knows how, I started digging through my local environment, and I saw my old Programming directory. I realized past-me had neatly organized the fundamentals of the language into a sequential 1-to-7 roadmap. 

**Full disclosure: This repo is pretty basic.** 

There are no massive frameworks, no advanced asynchronous streams, and no complex architecture patterns here. It’s just a raw, clean blueprint of the core language mechanics. If you want a quick, no-nonsense reference to look up basic Dart syntax without sitting through a 40-hour video tutorial, you may check this one out.

---

## 🗺️ The Learning Roadmap

The repository is structured sequentially through the bare essentials of Dart's modern, sound type system:

- [x] **(1) PEACE** — Mindset, initialization, and core concepts.
- [x] **(2) Variables Datatypes, and Operations** — Using var, string manipulation, and operators.
- [x] **(3) Control Flow** — `if-else` logic, `for` loops, and `while` execution.
- [x] **(4) Functions** — Definition, arguments, parameters, and clean execution.
- [x] **(5) Classes and Objects** — Basic Object-Oriented Programming (OOP) and constructors.
- [x] **(6) Lists and Maps**
- [x] **(7) Null Safety**
